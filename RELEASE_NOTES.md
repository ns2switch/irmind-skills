# First community skill catalog

Includes **aws-ec2-cryptomining 0.1.0**: CloudTrail-based EC2 provisioning and
credential-change triage with an isolated scripted synthetic episode. Control-plane
coverage is supported; actual mining requires additional workload evidence.

Requires IRMind v0.5.4 or later for the compiled production catalog trust root.
Run `/skills install catalog:aws-ec2-cryptomining`, inspect the preview and sign
admission. Core skills are not included. Downloading and admitting a methodology
does not extend case scope, tools or approvals.

The Ed25519-signed index fixes every package hash and release identity. Sigstore
bundles, GitHub provenance and an SBOM support independent verification; see README.
